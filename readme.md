# Proyecto-Pagina  web (venta de ropa)
## Descripcion
**Una página web de venta de ropa es una plataforma digital diseñada para mostrar, promocionar y vender prendas de vestir a través de internet. Su objetivo principal es ofrecer una experiencia de compra cómoda, rápida y atractiva para los usuarios. 
En esta ocacion el nombre de la pagina es campusShop.
## Tecnologias aplicadas
- html
- Css
- JavaScript (clases ES6, sin librerías)
- Github
-visual Code
## Funcionalidades
- Catálogo con búsqueda, categorías y filtros por talla, color y precio.
- Detalle de producto con selección de talla y color.
- Carrito con cantidades, eliminación con confirmación y total.
- Comparador de hasta 4 productos.
- Checkout con validación, historial de pedidos y perfil editable.
- Los datos se guardan en el navegador (localStorage); no hay backend.

## Estructura de JavaScript
- `js/core.js`: almacenamiento, utilidades de DOM, formato y validación.
- `js/catalog.js`: `Product` y `ProductRepository` (fuente única de productos).
- `js/services.js`: carrito, comparador, pedidos y perfil.
- `js/ui.js`: avisos, diálogos, selector de variantes y clase base de páginas.
- `js/pages/`: un controlador por página.

## Aprendizajes
En primer lugar, aprendí a utilizar herramientas básicas del desarrollo web como HTML5 y CSS3, lo que me ayudó a entender cómo estructurar y diseñar una página de manera ordenada y atractiva.
